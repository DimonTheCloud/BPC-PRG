# Тренажёр по переменным (пазлы)

Этот мини-курс сделан как «собери пазл» — от простого к сложному.

## Что делать прямо сейчас (пошагово)

1. Открой терминал в папке проекта.
2. Перейди в папку тренажёра:
   ```bash
   cd training_variables
   ```
3. Запусти первый уровень:
   ```bash
   python3 01_variables_basics.py
   ```
4. Замени значения в `TODO`, сохрани файл и снова запусти.
5. Когда увидишь `✅ Уровень 1 пройден`, переходи к уровню 2 и так далее.

## Где лежат файлы

Файлы созданы **локально в этом проекте** в папке:

- `training_variables/`

Если текущая корневая папка проекта `BPC-PRG`, то полный путь:

- `/workspace/BPC-PRG/training_variables/`

## Связь с GitHub (простыми словами)

- Я (ассистент) создаю/меняю файлы в локальной копии репозитория.
- Git — это история изменений (коммиты).
- GitHub — сайт, куда можно отправить эти изменения (push/PR), если репозиторий связан с удалённым сервером.
- То есть я не только «читаю инфо», я могу редактировать твои файлы в проекте.

## Порядок уровней

- `01_variables_basics.py` — что такое переменная, присваивание.
- `02_types_and_input.py` — типы (`int`, `float`, `str`, `bool`) и ввод.
- `03_operations_and_formulas.py` — вычисления и формулы.
- `04_mini_project_budget.py` — мини-проект (личный бюджет).
